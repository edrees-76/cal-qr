- **1.1: README أداة DemoData واختيار القالب الجديد تلقائياً في معاينة الطباعة (23 نوفمبر 2026)** — أساس `0edf0b2` (دمج #107). مستوى الخطورة: منخفض (واجهة ومنطق اختيار؛ لا مساس بالمخطّط ولا حمولة التوقيع ولا HMAC ولا الترقيم).

  - **قرار إدريس (محسوم):** بعد «قالب جديد» في المعاينة الفرديّة والدفعيّة يُختار القالب الجديد تلقائياً مع إبقاء الطابعة المختارة. **نُفِّذ:** `PaperTemplateViewModel.SavedTemplateId` (معرّف `template.Id` الذي يملؤه EF بعد `AddAsync`) يُكشف عبر `PaperTemplateDialog.SavedTemplateId`، ويُمرَّر إلى `LoadDataAsync(…, preferredTemplateId)`. وكان هناك خلل مرافق: إعادة التحميل تُعيد الطابعة من `LastPrinterName` (تُحفظ بعد الطباعة فقط) فتطمس اختيار المستخدم اليدويّ؛ صار الاختيار بدالّتين نقيّتين في `PrintSelectionRules` (الطابعة الحاليّة ثمّ المحفوظة ثمّ الأولى؛ القالب المطلوب ثمّ المحفوظ ثمّ الافتراضيّ ثمّ الأوّل). الإلغاء يترك الاختيار كما كان (`SavedTemplateId` = null).
